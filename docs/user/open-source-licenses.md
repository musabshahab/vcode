# Open source licenses

Codenine includes third-party software and adapted assets. To read their license and attribution
notices, open **Settings → About**, find **Open source licenses** under **Legal**, and select
**View licenses**.

The page lists the version when available, license identifier, and the parts of Codenine that include
or use the item. Select a row to read the complete notice text. Use the search field to find a package,
version, license, or app component.
